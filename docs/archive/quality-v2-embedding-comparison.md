# 固定 v5 语料的 Embedding 开发集对照

三种模型均完成同一套 108 道可回答开发题、7,873 个逻辑块的检索对照。106 道文本可评分问题含 118 个必需证据组；两个视觉问题不冒充文本命中，12 道拒答题留在后续完整问答评测。原始 v1 题集、旧结果以及 Qwen 首次 BF16 数值失败记录全部保留。

以下使用已封存 evidence-v2 的有限等价表示，组内取 OR，组间全部计入分母。开发集等价表示修订属于事后表示修复；模型间比较使用相同修订版本，不能把表示修复本身算作模型收益。

| Embedding | 纯向量 Recall@10 | 纯向量 Recall@80 | BM25+RRF10 Recall@10 | BM25+RRF10 Recall@80 |
|---|---:|---:|---:|---:|
| multilingual-e5-base | 77/118（65.25%） | 101/118（85.59%） | 89/118（75.42%） | 103/118（87.29%） |
| BGE-M3 dense | 90/118（76.27%） | 104/118（88.14%） | 93/118（78.81%） | 112/118（94.92%） |
| Qwen3-Embedding-0.6B | 86/118（72.88%） | 106/118（89.83%） | 96/118（81.36%） | 108/118（91.53%） |

BM25 与 dense 各使用保存的前80条，等权 RRF，重复逻辑块合并，chunk ID 决定并列顺序；这些结果均未重排。相同排名在 RRF30/60 下也有完整结果，BGE 的 Recall@80 均为112/118，Recall@10分别为92/118、92/118，RRF10的 novel-group nDCG@10 也最高。因此下一阶段暂用 **BGE-M3 dense + BM25、RRF10** 冻结60条候选，公平比较 BGE 与 Qwen 两种重排器。选择依据是进入重排前的候选覆盖及开发集排序；Qwen在未重排的前10条覆盖更高，仍如实保留。

**112/118=94.915254%，低于95%门槛，不能四舍五入为通过。** 这一选择不是生产模型定型。候选池60条的覆盖另行统计，不能直接继承80条覆盖成绩；后续还需查询规划、补检、上下文与完整问答对照。

95%证据簇 bootstrap 区间（104簇、1,000次、seed1729）：BGE混合 Recall@80为90.60%–98.32%，相对E5的配对差为+7.63个百分点，区间+2.59至+13.16；Recall@10配对差+3.39个百分点，区间−2.48至+9.48。该开发集分析不能证明全部类型和未见资料都获益，也没有做盲测显著性宣称。

资源记录需按实验版本解释：E5/BGE为v3工具，输出数组FP32但实际参数精度未记录；Qwen为v4显式FP32，已验证全部参数类型，10,763个向量窗口对应原7,873个逻辑块。Qwen文档编码阶段约14,458秒，worker+Qdrant采样峰值3.559GiB。v4更换了监控方式，E5还复用了经校验的索引向量，因此跨版本墙钟时间不能当作同条件速度对比，离线峰值也不代替完整应用验收。
